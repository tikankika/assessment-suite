# Setup Guide

> Step-by-step instructions to get Assessment Suite running on a new machine.

---

## Requirements

- **Claude Desktop** installed ([download](https://claude.ai/download))
- **Python 3.10+** (`python3 --version`) — see [Python alternatives](#python-alternatives-if-your-system-version-is-below-310) if your version is older
- **Node.js 18+** (`node --version`)
- **Git** (`git --version`)

---

## Step 1: Clone the repository

```bash
git clone https://github.com/tikankika/assessment-suite.git
cd assessment-suite
```

---

## Step 2: Install the Python package (assessment-data-mcp)

First check your Python version — it decides which option you need:

```bash
python3 --version
```

### Option A: A virtual environment via `uv` (recommended — required if below 3.10)

macOS ships with Python 3.9, which is too old (the package needs 3.10+). `uv`
creates a virtual environment with a recent Python regardless of your system
version, so this is the safe default on macOS:

```bash
cd packages/assessment-data-mcp

# Install uv if missing: brew install uv (or curl -LsSf https://astral.sh/uv/install.sh | sh)
uv venv            # Creates .venv/ with Python 3.10+
uv pip install -e .
```

### Option B: System Python (only if `python3 --version` is already 3.10+)

If — and only if — your system `python3` reports 3.10 or higher:

```bash
cd packages/assessment-data-mcp
pip3 install -e .
```

> **Important:** note the path to the venv's Python — you need it in Step 5.
> It is: `<your-path>/packages/assessment-data-mcp/.venv/bin/python3`

**Verify (adjust the python path to match your option):**
```bash
# Option A (venv):
.venv/bin/python3 -c "import assessment_data_mcp; print('OK')"

# Option B (system Python):
python3 -c "import assessment_data_mcp; print('OK')"
```

---

## Step 3: Build the TypeScript package (assessment-mcp)

```bash
cd ../assessment-mcp
npm install
npm run build
```

**Verify that the build succeeded:**
```bash
ls dist/server.js && echo "OK"
```

> **Note:** the entry point is `dist/server.js` (NOT `dist/index.js`).

---

## Step 4: Create a workspace folder

Assessment Suite protects your files through **workspace lockdown**: the MCP servers may
only read and write inside **one folder** that you choose. Everything outside it is
invisible to the tools — they cannot reach the rest of your home directory, your synced
folders, or other projects, even if Claude tries. (See [SECURITY.md](../SECURITY.md) for
the full security model.)

### Choose a location and create the folder

Choose a folder to hold all your assessment projects. Common choices:

```bash
# Option 1: under your home directory
mkdir -p ~/assessment_workspace

# Option 2: synced via Nextcloud / iCloud / Dropbox
mkdir -p ~/Nextcloud/assessment_workspace
```

> **Avoid these workspaces (too broad or system-critical):**
> - `/`, your home directory itself (`~`), `~/Documents`, `~/Desktop`
> - Folders with sensitive data you do not want the MCP servers to be able to read

### Note the path

```bash
cd ~/assessment_workspace   # or the folder you chose
pwd
# Example: /Users/yourname/assessment_workspace
```

You need this path in Step 5 (Claude Desktop configuration).

### What goes in the workspace?

```
~/assessment_workspace/
├── project_courseA/       ← one project per course/exam
│   ├── 01_original/       ← you copy in the exam, rubric, and answers manually
│   ├── 02_markdown/       ← generated by the MCP servers
│   └── ...
└── project_courseB/
    └── ...
```

No files are copied automatically — you copy the originals (exam, rubric, student answers)
in manually before Phase 1. The MCP servers never read outside the workspace.

## Step 5: Configure Claude Desktop

### Find your absolute path

```bash
cd ../..   # back to assessment-suite
pwd
# Example: /Users/yourname/projects/assessment-suite
```

### Open the Claude Desktop configuration

**macOS:**
```bash
open ~/Library/Application\ Support/Claude/
# Edit (or create) claude_desktop_config.json
```

**Windows:**
```bash
explorer %APPDATA%\Claude
```

### Configuration file

Replace `/ABSOLUTE/PATH/TO` with your actual path from `pwd` above.

**Choose the right variant depending on your Python installation (Step 2):**

Replace `/ABSOLUTE/PATH/TO/assessment-suite` with your installation path and
`/ABSOLUTE/PATH/TO/assessment_workspace` with the workspace path from Step 4.

#### If you used Option A (venv):

```json
{
  "mcpServers": {
    "assessment": {
      "command": "node",
      "args": [
        "/ABSOLUTE/PATH/TO/assessment-suite/packages/assessment-mcp/dist/server.js",
        "--workspace",
        "/ABSOLUTE/PATH/TO/assessment_workspace"
      ]
    },
    "assessment-data": {
      "command": "/ABSOLUTE/PATH/TO/assessment-suite/packages/assessment-data-mcp/.venv/bin/python3",
      "args": [
        "-m", "assessment_data_mcp.server",
        "--workspace",
        "/ABSOLUTE/PATH/TO/assessment_workspace"
      ],
      "cwd": "/ABSOLUTE/PATH/TO/assessment-suite/packages/assessment-data-mcp"
    }
  }
}
```

#### If you used Option B (system Python 3.10+):

```json
{
  "mcpServers": {
    "assessment": {
      "command": "node",
      "args": [
        "/ABSOLUTE/PATH/TO/assessment-suite/packages/assessment-mcp/dist/server.js",
        "--workspace",
        "/ABSOLUTE/PATH/TO/assessment_workspace"
      ]
    },
    "assessment-data": {
      "command": "python3",
      "args": [
        "-m", "assessment_data_mcp.server",
        "--workspace",
        "/ABSOLUTE/PATH/TO/assessment_workspace"
      ],
      "cwd": "/ABSOLUTE/PATH/TO/assessment-suite/packages/assessment-data-mcp"
    }
  }
}
```

> **Important:** with a venv, `command` must point at the venv's Python
> (`.../.venv/bin/python3`), NOT the system Python (`python3`). Otherwise the server will
> not find the installed packages.

---

## Step 6: Restart Claude Desktop

1. **Quit completely** (Cmd+Q on Mac, not just closing the window)
2. Wait 5 seconds
3. Open Claude Desktop again

---

## Step 7: Verify

In Claude Desktop, ask:
```
Which assessment MCP tools do you have available? List them all.
```

You should see **43 tools across the two servers** (32 from the assessment
server, 11 from the data server):

- The **assessment server (TypeScript)** provides tools for Phase 4 (rubric and exam
  analysis), Phase 6 (assessment), and Phases 9–14 (synthesis and feedback), plus
  cross-phase and utility tools.
- The **data server (Python)** provides tools for Phases 1–3 (setup, conversion,
  annotation), Phase 5 (extraction), and Phases 7–8 (reports and quantitative summaries).

If Claude lists tools spanning those phases, the setup is working. If it lists none — or
only some — see Troubleshooting below.

## Troubleshooting

### Problem: no tools appear

**Cause:** the server is not starting.

```bash
# Test the TypeScript server manually:
node /YOUR/PATH/assessment-suite/packages/assessment-mcp/dist/server.js

# Test the Python server:
cd /YOUR/PATH/assessment-suite/packages/assessment-data-mcp
python3 -m assessment_data_mcp.server
```

If you see error messages, read on.

### Problem: "Cannot find module" (TypeScript)

`dist/` is not version-controlled in git. You MUST build locally:

```bash
cd packages/assessment-mcp
npm install
npm run build
```

### Problem: only SOME tools appear (e.g. phase9+ works but phase4 tools are missing)

**Most common cause:** a stale build. `dist/server.js` was compiled from an older version
of the code.

```bash
cd packages/assessment-mcp

# Check the latest commit
git log --oneline -1

# Clean and rebuild
rm -rf dist
npm run build

# Verify — should show around 30 files
ls dist/tools/*.js | wc -l
```

**Restart Claude Desktop after rebuilding.**

### Problem: wrong path in config

```bash
# Common mistake: dist/index.js (DOES NOT EXIST)
# Correct: dist/server.js

# Verify the file actually exists:
ls -la /YOUR/PATH/assessment-suite/packages/assessment-mcp/dist/server.js
```

### Problem: `ERROR: --workspace argument required`

**Cause:** workspace lockdown — the server refuses to start without a `--workspace` path
that limits its file access.

**Fix:** add the `--workspace` argument to both servers in `claude_desktop_config.json`:

```json
"args": [
  "/path/to/assessment-suite/packages/assessment-mcp/dist/server.js",
  "--workspace",
  "/path/to/assessment_workspace"
]
```

The workspace path should point at the folder you created in Step 4. See
[SECURITY.md](../SECURITY.md) for background on workspace lockdown.

### Problem: Python 3.9 (too old)

macOS ships with Python 3.9. Assessment Suite requires 3.10+.

```bash
# Check the version:
python3 --version

# If 3.9: use uv to create a venv with a newer Python
cd packages/assessment-data-mcp
uv venv
uv pip install -e .

# Update claude_desktop_config.json to point at the venv's Python:
# "command": "/path/to/.venv/bin/python3"
```

### Problem: missing Python dependencies

```bash
cd packages/assessment-data-mcp

# With system Python:
pip3 install -e .

# With venv:
.venv/bin/python3 -c "import pdfplumber; print('pdfplumber OK')"
.venv/bin/python3 -c "import mcp; print('mcp SDK OK')"
.venv/bin/python3 -c "import yaml; print('pyyaml OK')"
```

### Problem: JSON syntax error in config

```bash
# Validate the JSON:
python3 -m json.tool ~/Library/Application\ Support/Claude/claude_desktop_config.json
```

### Problem: Claude Desktop logs

```bash
# macOS — view MCP logs:
ls ~/Library/Logs/Claude/mcp*.log
tail -50 ~/Library/Logs/Claude/mcp-server-assessment.log
```

## Python alternatives if your system version is below 3.10

macOS ships with Python 3.9. You have several options:

| Method | Command |
|--------|---------|
| **uv (recommended)** | `brew install uv`, then `uv venv && uv pip install -e .` |
| **Homebrew Python** | `brew install python@3.11`, then `python3.11 -m pip install -e .` |
| **pyenv** | `pyenv install 3.11`, then `pyenv local 3.11 && pip install -e .` |

With any method other than system Python: update `claude_desktop_config.json` to point at
the correct Python binary.

## Updating to a new version

```bash
cd assessment-suite
git pull origin main

# Rebuild TypeScript (ALWAYS after git pull!)
cd packages/assessment-mcp
npm install
npm run build

# Update Python (choose the right variant):
cd ../assessment-data-mcp
pip3 install -e .          # system Python
# OR: uv pip install -e .   # venv

# Restart Claude Desktop
```
