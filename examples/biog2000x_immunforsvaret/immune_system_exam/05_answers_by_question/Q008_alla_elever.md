## Elev 10001_100000000_example (38 ord)

**Svar:**

Antikroppar kan neutralisera genom att blockera patogenen så att den inte kan infektera
celler, opsonisera genom att märka patogenen så att fagocyter äter upp den, och
agglutinera genom att klumpa ihop flera patogener så att de lättare oskadliggörs.
