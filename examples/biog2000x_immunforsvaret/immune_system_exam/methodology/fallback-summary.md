## Quality Symbols

| Symbol | Level | Description |
|--------|-------|-------------|
| ✓✓✓ | Excellent | Full understanding, correct terminology |
| ✓✓ | Good | Good understanding, minor gaps |
| ✓ | Basic | Basic understanding demonstrated |
| ⚠ | Incomplete | Partial, missing important elements |
| ✗ | Incorrect | Wrong or missing |
| - | Unanswered | No answer given |

---

## Core Principles

1. **Content before form** - Assess the content first, then the expression
2. **Transparency** - Always include the student's complete answer
3. **Concreteness** - Reference specific parts of the answer
4. **Generosity at E-level** - Give the student "benefit of the doubt"
5. **Forward-looking feedback** - "Next step" should be concrete and useful
